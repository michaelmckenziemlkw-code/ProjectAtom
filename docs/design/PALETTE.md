# Палитра мира

11 ноября 2026. Направление текущей процедурной версии: светлое голубое небо, тёплая земля и прохладная растительность. Цвета общие для пролога и управления; прежнего переключения с фиолетово-коричневого фона на голубой только при взлёте больше нет.

| Элемент | Цвет |
| --- | --- |
| Небо | RGB 0,24 / 0,52 / 0,74 |
| Воздух и туман | RGB 0,51 / 0,68 / 0,77 |
| Почва | #88665C, текстура тёплой глины |
| Мох / земляные берега | #386B66 |
| Растения | #609D83 |
| Камни | #7E95A3 |
| Кора | #483F48 |
| Опавшие листья | #D5A56B |
| Лужа | #4B798B |

Источник общих цветов — `src/render/palette.ts`; поверхность лужи и мокрые листья согласованы в `introStage.ts`. Свет янтарный, заполнение голубое, нижний свет холоднее прежнего коричневого. В солнечном портрете свет ослабляется ради силуэта. После удара снижены насыщенность/экспозиция; к передаче управления они плавно восстанавливаются. Сама базовая окраска неба остаётся одинаковой.

Это проход цвета на существующей геометрии. Модели окружения, материалы высокого качества и полноценная атмосферная перспектива потребуют дальнейшей художественной работы. Серьёзная подача и отсутствие шуточных подписей сохраняются.
