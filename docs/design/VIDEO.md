# Визуальное направление: «Видео»

## Задача

Настройки должны выглядеть как серьёзный интерфейс игры. Комический эффект возникает из поведения игры; интерфейс не объясняет шутку. Название вкладки — «Видео». Никаких «AAA Edition», «понарошку» и шуточных описаний технологий. Технический характер ограничений остаётся описан в документации разработчика.

## Референсы и границы исследования

Просмотрены два изображения меню, предоставленные пользователем в переписке, и запись нативного интерфейса Cyberpunk 2077 из [Native Settings](https://github.com/justarandomguyintheinternet/CP77_nativeSettings). В записи видны верхняя навигация, компактная сетка параметров, контрастные значения и отдельные пояснения. Это интерфейс игры с добавленными модом пунктами, не доказательство состава штатного меню графики. Дополнительный источник нативных экранов: [GameSettingsParser / Cyberpunk sample](https://github.com/billyfletcher5000/GameSettingsParser/tree/main/SampleProjects/cyberpunk_sample_project).

Пользователь обозначил Cyberpunk, Metro Exodus, Atomic Heart, GTA V и современные требовательные AAA как ориентиры. Полный свежий визуальный обзор всех этих игр не выполнен: Game UI Database и внешние хосты изображений недоступны по сетевой политике этой среды. Найденные GitHub-обсуждения RDR2 и Black Myth: Wukong не дали доступных изображений меню. GTA V, Alan Wake 2 и другие игры не выдаются здесь за просмотренные референсы. Это ограничение подборки, а не препятствие для разработки собственного интерфейса.

## Общие приёмы, принятые для ProjectAtom

| Приём | Решение |
| --- | --- |
| Ясная иерархия | Крупный заголовок «ВИДЕО», меньшие заголовки секций, повторяемые строки |
| Плотная сетка | Название слева, значение справа, постоянное выравнивание контролов |
| Контрастный фокус | Красная полоса и сдержанная заливка активной строки, видимый фокус с клавиатуры |
| Ограниченная палитра | Графитовые поверхности, светлый текст, красный акцент, голубые значения |
| Техническая типографика | Локальный Roboto Condensed с кириллицей; прописные названия технологий, умеренная разрядка |
| Контекст вместо слоганов | Нейтральное описание выбранной технологии в отдельной колонке |
| Разделение состояния | Реально измеренный FPS отдельно от установленного предела |
| Сдержанное оформление | Прямые углы, тонкие разделители, минимум декоративных элементов |

Единого универсального цвета или шрифта у AAA-проектов нет. Здесь заимствуются композиционные принципы, а не логотипы, фирменные шрифты, фоновые изображения или интерфейс конкретной игры целиком.

## Текущая реализация

В интерфейсе видны `NVIDIA HAIRWORKS`, `RAY TRACING`, `PATH TRACING`, `NVIDIA DLSS` и другие названия; регистр задаётся типографикой, а не случайной капитализацией. Шрифт и его OFL-лицензия поставляются в `public/fonts`, внешние шрифтовые сервисы не нужны.

Описания технологий написаны нейтрально. Они объясняют термины, а не заявляют о подключении реальных SDK. Программная логика прежняя: параметры управляют ограничением отрисовок, время и звук обновляются отдельно.

По последнему указанию пользователя сведения о пределах FPS пока оставлены в панели. Удаление этих диагностических сведений из будущей игры — отдельная последующая задача. Убраны все объясняющие шутку надписи из самого меню; документация сохраняет точное описание реализации.

На узком экране меню складывается в одну колонку и прокручивается. На широком экране список параметров и описание прокручиваются отдельно, а кнопка применения остаётся справа. Работа с клавиатурой, выбор уровней DLSS/FSR/XeSS и сброс сохраняются. F8 и сброс изменяют форму; результат вступает в силу после «Применить настройки».


## Проверка реализации

11 ноября 2026: npm run build прошёл; npm run test:unit — 11 прошли; полный npm test в системном Chromium — 6 прошли за 3,5 минуты, без пропусков. Браузерная проверка явно открывает вкладку «Видео» и проверяет отсутствие объясняющих шутку текстов. Проверены выбор технологий и режимов, фактические отрисовки на 5 FPS, сохранение скорости времени и сброс. Обновлены и просмотрены снимки широкого и узкого экранов. При сборке путь локального шрифта преобразован в относительный, чтобы сохранить поставку из папки dist.

Позднейшее уточнение: единое окно «Звук» / «Видео», громкость 0–100% и отложенное применение видео. Текущий предел, предварительный расчёт и реальный FPS разделены; вместо фиксированной таблицы используется [модель множителей](FPS.md). Размер и положение окна не зависят от активной вкладки.
