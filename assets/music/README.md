# WormTheme

`source/WormTheme.mid` — авторское исполнение пользователя на Kawai, сохранено без изменений: 517 нот, 352 события педали, MIDI format 0, PPQ 1920, карта темпа 120 BPM, последняя MIDI-отметка 131,173958 с. Живые длительности и динамика сохранены; темп не выравнивался.

`../../public/music/WormTheme.ogg` — стереофортепиано 44,1 кГц, около 134,174 с с трёхсекундным хвостом, около 2,3 МБ. Метаданные и SHA-256 исходника — `WormTheme.json`; длительность синематика берётся из них. Это виртуальный инструмент, не запись звука Kawai.

## Тембр и sustain

Активный инструмент — **FluidR3 GM Yamaha Grand Piano**, GM program 0, авторы SoundFont Frank Wen / Toby Smithe, лицензия MIT. Атрибуция и условия — `licenses/FluidR3-NOTICE.txt`. Сам SoundFont не входит в репозиторий. Авторство композиции и исполнения остаётся за пользователем; исходный MIDI не заменяется рендером.

Заменён прежний компактный TimGM6mb. События CC64 ранее передавались в синтезатор, но звук быстро затухал даже с удержанием. В новом рендере сохранены все исходные события педали и увеличено время спада струны (+900 timecents, примерно ×1,68). Это не прибавление реверберации: демпфер после отпускания педали по-прежнему гасит ноты, чьи клавиши отпущены. Аудиотест с отдельной нотой подтверждает удержание после key-up и затухание после pedal-up: +41,8 dB относительно версии без педали в окне 1–1,5 с, снижение на 54,8 dB после отпускания педали. Пиковая амплитуда полного PCM — около 0,202, клиппинга нет; gain музыки в игре 2,2 перед общим регулятором.

Значения CC64 сохраняются полностью; SoundFont не воспроизводит один в один физическую полупедаль, резонансы и DSP цифрового Kawai. SysEx настройки конкретного пианино в тембр не переносятся. Для точного тембра самого инструмента нужна аудиозапись с него.

## Повторный рендер

Нужны Python 3, системная libfluidsynth, FFmpeg и FluidR3_GM.sf2. Python-пакеты не нужны. Воспроизведению готовой игры эти инструменты тоже не нужны — она загружает только локальный Ogg.

В этой облачной среде SoundFont извлечён без установки в систему из официального Debian-пакета `https://deb.debian.org/debian/pool/main/f/fluid-soundfont/fluid-soundfont-gm_3.1-6_all.deb` в `/tmp/worm-fluid/usr/share/sounds/sf2/FluidR3_GM.sf2`. В новой среде использовать установленный файл либо повторно получить этот пакет и извлечь `dpkg-deb -x` в `/tmp`.

```sh
PIANO_SOUNDFONT=/usr/share/sounds/sf2/FluidR3_GM.sf2 python3 scripts/test_render_midi.py
python3 scripts/render_midi.py assets/music/source/WormTheme.mid /tmp/WormTheme.wav /usr/share/sounds/sf2/FluidR3_GM.sf2 > assets/music/WormTheme.json
ffmpeg -y -i /tmp/WormTheme.wav -c:a libvorbis -q:a 5 public/music/WormTheme.ogg
```

Тесты: парсер проверяет карту темпа, running status, velocity, note-off и CC64; аудиотест рендерит две одинаковые ноты с педалью/без неё и измеряет уровни до и после отпускания демпфера. Без переменной `PIANO_SOUNDFONT` аудиотест явно пропускается; для полной проверки обязательно задать путь к активному SoundFont. Шумовой кашель остаётся отдельным эффектом, музыка не зацикливается и не растягивается.
